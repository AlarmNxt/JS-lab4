# Практическая работа №4

## Тема

Массивы и строки в JavaScript.

## Запуск тестов

```bash
node tests.js
```

## Что нужно заполнить

Откройте `student-template.js` и заполните участки `TODO`.

Не изменяйте:

- названия функций;
- список параметров функций;
- блок `module.exports` в конце файла.

В этой работе используются уже изученные функции, циклы и условия. Для работы с массивами и строками разрешено применять методы, разобранные на занятии: `push()`, `includes()`, `slice()`, `split()`, `join()`, `trim()`, `indexOf()`, `startsWith()`, `endsWith()` и другие базовые методы из лекционного материала.

`map()`, `filter()` и `reduce()` для выполнения этой работы не требуются.

Полные условия, ограничения и примеры находятся в документе `Практическая_работа_4.docx`.

## Сдача

В репозитории должны находиться:

- заполненный `student-template.js`;

Перед отправкой обязательно выполните:

```bash
node tests.js
```

Все группы тестов должны завершиться успешно.
