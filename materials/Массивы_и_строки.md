# Массивы и строки в JavaScript

Массивы и строки часто встречаются вместе: строку можно разбить на части и получить массив, а массив — собрать обратно в строку. В этом блоке важно не столько запомнить все методы, сколько понять, **что хранится в переменной, изменяется ли исходное значение и какой результат возвращает метод**.

# Массивы

## 1. Создание массива

Массив хранит упорядоченный набор значений. Элементы могут иметь разные типы, хотя на практике обычно удобнее хранить в одном массиве однотипные данные.

```js
const numbers = [10, 20, 30, 40];
const mixed = [1, 'hello', true, null, [5, 6]];
```

Первый элемент имеет индекс `0`:

```js
console.log(numbers[0]); // 10
console.log(numbers[2]); // 30
```

Количество элементов хранится в свойстве `length`:

```js
console.log(numbers.length); // 4
```

Последний элемент можно получить двумя способами:

```js
console.log(numbers[numbers.length - 1]); // 40
console.log(numbers.at(-1));              // 40
```

Запись `numbers[-1]` не означает «последний элемент». Для отрицательного индекса используйте `at()`.

## 2. Изменение элемента

Массив — изменяемый объект. Элемент можно заменить по индексу:

```js
const values = [10, 20, 30];
values[1] = 99;

console.log(values); // [10, 99, 30]
```

## 3. Добавление и удаление элементов

### `push()` и `pop()`

`push()` добавляет элементы в конец массива. `pop()` удаляет последний элемент и возвращает его.

```js
const basket = ['чай', 'кофе'];

basket.push('молоко');
console.log(basket); // ['чай', 'кофе', 'молоко']

const last = basket.pop();
console.log(last);   // 'молоко'
console.log(basket); // ['чай', 'кофе']
```

### `unshift()` и `shift()`

`unshift()` добавляет элементы в начало массива, `shift()` удаляет первый элемент.

```js
basket.unshift('вода');
console.log(basket);

const first = basket.shift();
console.log(first);
```

Все четыре метода изменяют исходный массив.

## 4. `splice()` и `slice()` — похожие названия, разное поведение

### `splice()` изменяет массив

```js
const values = [10, 20, 30, 40, 50];
values.splice(1, 2);

console.log(values); // [10, 40, 50]
```

Первый аргумент — индекс начала, второй — количество удаляемых элементов. Через дополнительные аргументы можно вставлять новые значения:

```js
const values = [10, 20, 30];
values.splice(1, 1, 99, 100);

console.log(values); // [10, 99, 100, 30]
```

### `slice()` не изменяет исходный массив

```js
const numbers = [1, 2, 3, 4, 5, 6];
const part = numbers.slice(2, 5);

console.log(part);    // [3, 4, 5]
console.log(numbers); // [1, 2, 3, 4, 5, 6]
```

Правая граница в `slice(start, end)` не включается.

## 5. Перебор массива

Обычный `for` удобен, когда нужен индекс:

```js
const numbers = [5, 10, 15];

for (let i = 0; i < numbers.length; i++) {
  console.log(i, numbers[i]);
}
```

`for...of` удобен, когда нужны сами значения:

```js
for (const number of numbers) {
  console.log(number);
}
```

Например, сумма элементов:

```js
let sum = 0;

for (const number of numbers) {
  sum += number;
}

console.log(sum);
```

`for...in` для массивов обычно не используют как основной вариант: он перебирает ключи, а не значения, и ключи приходят как строки.

## 6. Поиск значения и удаление повторов

`includes()` отвечает, встречается ли значение в массиве:

```js
const numbers = [5, 10, 15];
console.log(numbers.includes(10)); // true
```

С его помощью можно собрать массив уникальных значений:

```js
const source = [1, 2, 1, 3, 2, 4];
const unique = [];

for (const value of source) {
  if (!unique.includes(value)) {
    unique.push(value);
  }
}

console.log(unique); // [1, 2, 3, 4]
```

## 7. Несколько замечаний по массивам

- `pop`, `push`, `shift`, `unshift`, `splice`, `reverse`, `sort`, `fill` изменяют исходный массив.
- `slice` возвращает новый массив.
- `delete array[index]` удаляет свойство, но оставляет «пустое место» и не уменьшает `length`. Для обычного удаления элементов лучше использовать `splice()`.
- `sort()` без функции сравнения сортирует значения как строки. К числовой сортировке вернёмся отдельно.
- `map()`, `filter()` и `reduce()` полезны, но в этой работе не обязательны. Сначала важно уверенно научиться обрабатывать массив обычным циклом.

# Строки

## 8. Создание строк

В JavaScript используются одинарные, двойные и обратные кавычки:

```js
const first = 'hello';
const second = "world";
const name = 'Иван';
const third = `Привет, ${name}!`;
```

Обратные кавычки позволяют вставлять выражения через `${...}` и создавать многострочные строки.

## 9. Длина и символы

```js
const text = 'hello world';

console.log(text.length); // 11
console.log(text[0]);     // h
console.log(text.at(-1)); // d
```

В отличие от массива, строка неизменяема. Отдельный символ нельзя заменить по индексу. В обычном режиме такая попытка не изменит строку, а в строгом режиме (`"use strict"`) может привести к `TypeError`. Поэтому для изменения создают новую строку:

```js
text = 'H' + text.slice(1);
console.log(text); // Hello
```

## 10. Регистр

```js
const text = 'JavaScript';

console.log(text.toLowerCase()); // javascript
console.log(text.toUpperCase()); // JAVASCRIPT
```

Методы возвращают новую строку; исходная строка сама по себе не меняется.

## 11. Поиск внутри строки

```js
const text = 'JavaScript is JavaScript';

console.log(text.includes('Script'));     // true
console.log(text.indexOf('JavaScript'));  // 0
console.log(text.lastIndexOf('JavaScript'));
```

Если `indexOf()` ничего не нашёл, он возвращает `-1`.

Проверка начала и конца:

```js
const url = 'https://example.com/catalog';

console.log(url.startsWith('https://')); // true
console.log(url.endsWith('/catalog'));   // true
```

## 12. Получение части строки

Чаще всего достаточно `slice()`:

```js
const text = 'hello world';

console.log(text.slice(0, 5)); // hello
console.log(text.slice(6));    // world
console.log(text.slice(-5));   // world
```

Также существует `substring()`, но у него другое поведение с отрицательными значениями и переставленными границами. Для новых задач удобнее последовательно пользоваться `slice()`.

`substr()` встречается в старом коде, но считается устаревшим и в новых решениях не рекомендуется.

## 13. `split()` и `join()`

`split()` разбивает строку и возвращает массив:

```js
const text = 'red green blue';
const words = text.split(' ');

console.log(words); // ['red', 'green', 'blue']
```

`join()` делает обратное — собирает массив в строку:

```js
console.log(words.join(' | ')); // red | green | blue
```

Так можно, например, поменять порядок слов:

```js
console.log(text.split(' ').reverse().join(' '));
```

## 14. Очистка пробелов

```js
const value = '   hello world   ';

console.log(value.trim());
console.log(value.trimStart());
console.log(value.trimEnd());
```

## 15. Замена текста

`replace()` заменяет первое совпадение:

```js
const text = 'one one one';
console.log(text.replace('one', 'two')); // two one one
```

`replaceAll()` заменяет все совпадения:

```js
console.log(text.replaceAll('one', 'two')); // two two two
```

## 16. Строковые методы в задаче

Например, оставить только первые три слова:

```js
const text = 'один два три четыре пять';
const words = text.split(' ');
const shortText = words.slice(0, 3).join(' ') + '...';

console.log(shortText); // один два три...
```

Другой пример — разбор адреса сайта без объекта `URL`:

```js
const url = 'https://example.com/catalog/item/?id=15';

const protocolEnd = url.indexOf('://');
const protocol = url.slice(0, protocolEnd);
const domainStart = protocolEnd + 3;
const pathStart = url.indexOf('/', domainStart);
const queryStart = url.indexOf('?', pathStart);

const domain = url.slice(domainStart, pathStart);
const uri = url.slice(pathStart, queryStart);
const query = url.slice(queryStart + 1);

console.log(protocol);
console.log(domain);
console.log(uri);
console.log(query);
```

## 17. На что обратить внимание

1. Индексация массива и строки начинается с нуля.
2. Массив можно изменять по индексам, строку — нельзя.
3. Проверяйте, изменяет ли метод исходный массив или возвращает новый.
4. `slice()` не включает правую границу.
5. `indexOf()` возвращает `-1`, если значение не найдено.
6. `split()` превращает строку в массив, `join()` — массив в строку.
7. В задачах лучше сначала получить понятные промежуточные значения, а уже потом собирать финальный результат.
## 18. Перебор массива: `for...of`, `for...in` и `forEach()`

После обычного цикла `for` у массивов есть несколько удобных способов перебора.

### `for...of`

`for...of` сразу даёт значение текущего элемента:

```js
const numbers = [10, 20, 30];

for (const number of numbers) {
  console.log(number);
}
```

Если индекс не нужен, это один из самых простых способов пройти по массиву.

### `for...in`

`for...in` перебирает ключи. У массива такими ключами обычно являются индексы:

```js
const numbers = [10, 20, 30];

for (const index in numbers) {
  console.log(index, numbers[index]);
}
```

Важно: `index` здесь является строкой. Для обычного перебора элементов массива чаще используют `for...of`, а `for...in` особенно полезен при работе с объектами.

### `forEach()`

`forEach()` вызывает переданную функцию для каждого элемента массива:

```js
const fruits = ['apple', 'banana', 'orange'];

fruits.forEach(function (fruit, index) {
  console.log(`${index + 1}: ${fruit}`);
});
```

То же самое можно записать стрелочной функцией:

```js
fruits.forEach((fruit, index) => {
  console.log(`${index + 1}: ${fruit}`);
});
```

`forEach()` удобен для выполнения действия над каждым элементом, но сам по себе не создаёт новый массив.

## 19. Callback-функции в методах массивов

`forEach()`, `map()`, `filter()` и `reduce()` принимают функцию. Такая функция передаётся другому коду и вызывается им в нужный момент. В этом контексте её называют **callback-функцией**.

```js
const numbers = [1, 2, 3];

numbers.forEach((number) => {
  console.log(number);
});
```

Здесь стрелочная функция `(number) => { ... }` является callback-функцией.

## 20. `map()` — преобразование элементов

`map()` вызывает функцию для каждого элемента и возвращает **новый массив** из полученных результатов.

```js
const numbers = [1, 2, 3, 4];

const doubled = numbers.map((number) => {
  return number * 2;
});

console.log(doubled); // [2, 4, 6, 8]
console.log(numbers); // [1, 2, 3, 4]
```

Ещё один типичный пример — преобразование строк в числа:

```js
const values = ['10', '20', '30'];
const converted = values.map((value) => Number(value));

console.log(converted); // [10, 20, 30]
```

Главная идея: **один элемент вошёл — одно преобразованное значение вышло**.

## 21. `filter()` — отбор элементов

`filter()` оставляет только те элементы, для которых callback-функция вернула `true`.

```js
const numbers = [1, 2, 3, 4, 5, 6];

const even = numbers.filter((number) => {
  return number % 2 === 0;
});

console.log(even); // [2, 4, 6]
```

Можно фильтровать и строки:

```js
const words = ['cat', 'javascript', 'dog', 'browser'];
const longWords = words.filter((word) => word.length >= 5);

console.log(longWords); // ['javascript', 'browser']
```

Главная идея: **элемент либо остаётся в новом массиве, либо нет**.

## 22. `reduce()` — сведение массива к одному результату

`reduce()` последовательно обрабатывает элементы и накапливает единый результат.

```js
const numbers = [1, 2, 3, 4, 5];

const sum = numbers.reduce((accumulator, number) => {
  return accumulator + number;
}, 0);

console.log(sum); // 15
```

Здесь:

- `accumulator` — накопленное значение;
- `number` — текущий элемент массива;
- `0` — начальное значение аккумулятора.

Тот же результат обычным циклом:

```js
let sum = 0;

for (const number of numbers) {
  sum += number;
}
```

`reduce()` полезен, когда из массива нужно получить одно итоговое значение: сумму, произведение, строку, объект со статистикой и т. д.

## 23. Связка строк и методов массивов

`split()` превращает строку в массив. После этого к полученному массиву можно применять `map()` или `filter()`, а затем собрать результат обратно через `join()`.

```js
const text = 'javascript is very useful';

const result = text
  .split(' ')
  .map((word) => word.toUpperCase())
  .join(' ');

console.log(result); // JAVASCRIPT IS VERY USEFUL
```

Пример с фильтрацией:

```js
const text = 'one javascript two browser three';

const result = text
  .split(' ')
  .filter((word) => word.length > 3)
  .join(' ');

console.log(result); // javascript browser three
```

Такой подход хорошо показывает связь двух тем: **строка → массив → обработка → строка**.

## 24. Что выбрать

- `for` — когда нужен индекс и полный контроль над шагом цикла;
- `for...of` — когда нужны значения массива;
- `for...in` — когда нужны ключи, прежде всего у объектов;
- `forEach()` — выполнить действие для каждого элемента;
- `map()` — преобразовать каждый элемент и получить новый массив;
- `filter()` — отобрать часть элементов в новый массив;
- `reduce()` — получить из массива одно итоговое значение.

Не нужно стремиться заменить все обычные циклы методами массивов. Важно понимать задачу и выбирать вариант, который делает решение понятным.
